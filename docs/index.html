Enterprise Architecture

Designed for Production Reliability

Zero unhandled exceptions, decoupled LLM execution, and deterministic state transitions.

Figure 1.0: Complete light-theme architectural workflow featuring Meta Cloud API webhook authentication, deduplication, structured LLM extraction, two-phase slot reservation, and automated human handoff.

1

Cryptographic Ingestion

HMAC-SHA256 signature verification over raw request body with constant-time equality checks and wamid deduplication.

2

Structured LLM Guardrails

Pydantic V2 schemas, <CUSTOMER_INPUT> delimiter fencing against prompt injections, and decoupled deterministic rules.

3

Two-Phase Calendar Lock

Prevents race conditions by re-verifying slot availability right before booking. Self-healing background CRM reconciliation worker.

4

Immediate Human Escalation

Multi-signal sentiment and loop detection triggers instantaneous cessation of bot replies and dispatches Slack Block Kit cards.
